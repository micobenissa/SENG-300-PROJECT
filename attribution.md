# P1 attribution

## How we used AI

We used AI to clarify questions about the assignment, ask technical questions when we got stuck, and get ideas for our design. It helped us compare different approaches and plan how we wanted to build the project. We used it as a tool for asking questions, similar to looking up technical information, and checked the answers against the assignment and client emails.
